# CodeHands AI Design System

This directory documents the design system, tokens, and visual principles for the **CodeHands AI** workspace.

## Documents

- [Colors](colors.md) — Dark-first palette (`#0B0D16`, `#7857FF`, `#27B7F5`), status indicators, and contrast rules
- [Typography](typography.md) — Font stacks (`Inter` + `JetBrains Mono`) and hierarchy
- [Layout and Spacing](layout-and-spacing.md) — Multi-panel application shell, task workspace, and dock layout
- [Components](components.md) — Reusable component specs (diff viewer, workflow editor, model routing, terminal)
- [Design Tokens](design-tokens.json) — Machine-readable token specifications
