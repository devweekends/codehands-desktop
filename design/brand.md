# Brand

## Identity

**CodeHands AI** — *"Engineering work, orchestrated."*

CodeHands AI is an autonomous engineering workspace where software engineers and tech leads connect their repositories, submit development tasks, configure multi-agent AI workflows, inspect generated code changes, and review execution in real time.

## Visual Character

- **Linear-grade Usability:** Fast, keyboard-driven navigation, clean density, thoughtful keyboard shortcuts (e.g., `Ctrl+K` command palette).
- **Vercel-grade Sophistication:** Deep obsidian backgrounds (`#0B0D16`), sharp hairline borders (`#272D40`), and vivid violet (`#7857FF`) and cyan (`#27B7F5`) accents.
- **GitHub-grade Information Architecture:** Reliable diff viewers, branches, commit metadata, staged changes, and inline PR-style comments.
- **High Agency & Control:** Changes are staged and reviewed before commits or merges. The developer is in command at all phases of execution.
